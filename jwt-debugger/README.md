# 🔑 JWT Debugger

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Decode and debug JSON Web Tokens securely in the browser. View header, payload, claims descriptions, and expiry status without sending your token anywhere.

## ✨ Features

- Header & payload decoding
- Standard claims descriptions
- Expiry & validity indicators
- Color-coded token sections
- 100% client-side & secure
