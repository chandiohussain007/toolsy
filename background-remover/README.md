# 🖼️ Background Remover

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

A premium, client-side tool to remove backgrounds from images using auto-chroma detection, tolerance controls, and manual brush tools — with a live split compare view. 100% runs in the browser. No server, no uploads.

## ✨ Features

- Auto-chroma background removal
- Tolerance slider for fine control
- Manual brush erase/restore
- Split compare before/after view
- PNG export with transparency
