# 🏠 ToolSy Hub Launcher

> The central dashboard for the **[ToolSy](https://github.com/chandiohussain007/toolsy)** collection — a searchable grid of all 19 premium web utility tools.

## ✨ Features

- Searchable card grid by name, description, or tag
- Tactile Soft UI 2.0 design — glassmorphism + neomorphic cards
- Haptic-click animations on every card
- Links to each individual tool's Vercel deployment
- Fully responsive for mobile and desktop

## 🛠 Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React icons
- Tactile Soft UI 2.0 design system

## 🚀 Run Locally

```bash
npm install
npm run dev
```

## 🏗 Build

```bash
npm run build
```

## ☁️ Deploy to Vercel

1. Import this repo on [Vercel](https://vercel.com)
2. Set **Root Directory** to `hub-launcher`
3. Click **Deploy** — Vite is auto-detected
