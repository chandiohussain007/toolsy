# 💧 PDF Watermarker

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Add a customisable text watermark to every page of a PDF. Control the text, opacity, font size, and rotation angle — all in the browser.

## ✨ Features

- Custom watermark text
- Opacity & size controls
- Rotation angle slider
- Applies to all pages
- Client-side processing
