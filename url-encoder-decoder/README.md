# 🔗 URL Encoder / Decoder

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Encode and decode URL strings and query parameters instantly. Paste a full URL to parse all its components, or build one from scratch.

## ✨ Features

- URL encoding & decoding
- Query string parsing
- Copy individual params
- Real-time output
- Supports URI & encodeURIComponent modes
