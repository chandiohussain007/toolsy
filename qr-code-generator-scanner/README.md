# 📱 QR Code Generator & Scanner

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Generate custom QR codes from any text or URL, and scan QR codes using your device camera or an uploaded image.

## ✨ Features

- Generate QR from text/URL
- Live camera scanner
- Image upload scan
- Custom colors & sizes
- Download as PNG

```bash

npm run dev
```

```bash
npm run build
```
