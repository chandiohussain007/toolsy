# 📋 JSON Formatter & Validator

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Paste raw JSON and instantly validate, format, and explore it in an interactive tree view. Color-coded errors pinpoint exactly where your JSON breaks.

## ✨ Features

- Real-time validation
- Interactive collapsible tree
- Minify & prettify
- Error line highlighting
- Copy formatted output

```bash

```

```bash

```
