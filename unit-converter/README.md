# 📏 Unit Converter

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

A fast, dual-column unit converter covering length, weight, temperature, area, volume, speed, and more. Change one value and see all others update instantly.

## ✨ Features

- 10+ unit categories
- Dual-column live sync
- Smooth animations
- Keyboard friendly
- Zero dependencies beyond React
