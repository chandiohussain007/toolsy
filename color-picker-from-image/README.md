# 🎨 Color Picker from Image

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Upload an image and hover over any pixel to extract its exact color. Uses a magnifying loupe for precision and exports HEX and RGB values.

## ✨ Features

- Magnifying loupe for pixel-perfect picking
- HEX & RGB output
- Copy to clipboard
- Zoom controls
- Supports JPEG, PNG, WebP
