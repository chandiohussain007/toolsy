# 🔢 HTML Entity Encoder & Decoder

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Encode special characters into their HTML entity equivalents and decode them back. Supports both named entities and numeric codes.

## ✨ Features

- Full named entity support
- Numeric HTML code output
- Real-time encoding/decoding
- Copy to clipboard
- Basic & comprehensive mapping modes
