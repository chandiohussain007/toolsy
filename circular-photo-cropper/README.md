# ⭕ Circular Photo Cropper

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Crop any image into a perfect circle with transparent background. Supports drag, zoom, and pan to position your photo exactly how you want it.

## ✨ Features

- Drag, zoom & pan positioning
- Transparent PNG export
- Aspect-ratio locked circle crop
- Real-time preview
- No server uploads
