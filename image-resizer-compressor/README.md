# 📐 Image Resizer & Compressor

> Part of the **[ToolSy](https://github.com/chandiohussain007/toolsy)** — a collection of premium, free, client-side web utilities.

Resize and compress images directly in your browser. Lock aspect ratio, set custom dimensions, control quality, and download optimised images instantly.

## ✨ Features

- Drag-and-drop upload
- Aspect ratio lock
- Custom width & height
- Quality slider
- JPEG/PNG output
